How I run agentic workflows

Ticket in. Reviewed PR out.

  1. 01

    Intake

    Requests from Slack, email or the tracker become structured tickets.

  2. 02

    Spec

    A speccing agent reads the repo and writes acceptance criteria.

  3. 03

    Plan

    Tasks, touched modules and risk flags, checked against past decisions.

  4. 04

    Approve

    An engineer signs off on spec and plan before code is written.

  5. 05

    Code

    Coding agents implement on a branch, in the repo's own conventions.

  6. 06

    Check

    Lint, tests and AI code review run on every pull request.

  7. 07

    Merge

    A person reviews the diff and merges. Agents never ship alone.

  8. 08

    Learn

    Review decisions feed a wiki, so the next run starts smarter.
